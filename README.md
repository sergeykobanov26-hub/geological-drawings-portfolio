# Портфолио геологических чертежей

Примеры графических работ, выполненных в AutoCAD: геологический профильный разрез и комплексный геологический документ (карта + разрез + колонка).

## О портфолио

Здесь собраны чертежи, демонстрирующие навыки работы в AutoCAD и оформления геологической графики по стандартам.

## Работа 1. Геологический профильный разрез по линии скважин 1, 8, 4, 2, 6

**Тип:** профильный геологический разрез.
**Масштаб:** M2 = M0 = 1:10 000.
**Инструмент:** AutoCAD.

**Что показано:**
- Стратиграфические подразделения (K₁, K₂, J₃, J₂, J₁, T₃)
- Проектные отметки скважин (схв. 1, 8, 4, 2, 6)
- Ориентация профиля: СЗ ↔ ЮВ
- Ось глубин от +200 до −1200 м

![Геологический профильный разрез](drawings/01_geological_profile.png)

**Что демонстрирует:** построение разреза по данным бурения, работа с масштабом, оформление стратиграфической раскраски, подписи скважин.

## Работа 2. Геологическая карта М 1:25 000 с комплексом графических приложений

**Тип:** комплексный геологический документ.
**Инструмент:** AutoCAD.

**Состав работы:**
- Геологическая карта М 1:25 000
- Геологический разрез по линии А–Б (1:1 000)
- Литолого-стратиграфическая колонка (системы D, C, P, N)
- Таблица глубин проектных скважин
- Условные обозначения

![Геологическая карта М 1:25 000](drawings/02_geological_map_m25k.png)

**Что демонстрирует:** построение комплексного геологического документа — карта + разрез + колонка + таблицы + легенда. Умение работать со стратиграфией, литологией, оформлением.

## Инструменты

- **AutoCAD** — 2D-черчение, работа со слоями, блоками, масштабирование, оформление чертежей
- Стандарты оформления геологической графики
